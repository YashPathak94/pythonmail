Hi Team,

We propose a **3-week Argo CD POC** to validate GitOps-based application deployment on Amazon EKS.

**Proposed timeline**

* **Week 1 – Setup and Design:** Finalize scope, configure Argo CD, GitHub Enterprise/CodeConnections, IAM, RBAC, AppProject and repository access.
* **Week 2 – Implementation and Testing:** Deploy a sample application across `idev`, `idevb` and `idevc`, and validate synchronization, drift detection, self-healing, pruning and rollback.
* **Week 3 – Operational Readiness:** Validate monitoring, notifications, security controls, documentation, knowledge transfer and management demonstration.

**POC framework**

1. **Define:** Confirm scope, application, stakeholders and success criteria.
2. **Design:** Define architecture, Git repository structure, IAM/RBAC and deployment model.
3. **Build:** Configure Argo CD and deploy the sample application.
4. **Validate:** Test repository connectivity, multi-namespace deployment, automated sync, rollback and access restrictions.
5. **Decide:** Review results and provide a go, conditional-go or no-go recommendation for production rollout.

**Expected deliverables**

* Working Argo CD deployment across three namespaces.
* Test results and evidence.
* Architecture and operational runbook.
* Identified risks and production-readiness gaps.
* Recommended production rollout plan.

The timeline assumes that the EKS cluster, GitHub repository, IAM approvals and network access are available. Delays in access or security approvals may affect the schedule.
